登录遇到问题？

先安装 Codex CLI，再点击“使用 ChatGPT 登录”。如果网页授权未完成，可在终端运行 codex login，然后返回点击“检查登录”。登录凭据由 Codex 保存。

安装 Codex CLI ↗ · 查看登录帮助 ↗
怎么使用？先完成一次只读审查
  1. 检查环境并登录：确认 Git、Codex CLI 可用，点击“使用 ChatGPT 登录”完成浏览器授权。
  2. 添加项目：填写要操作的本地 Git 仓库绝对路径，例如 /Users/你的用户名/Projects/my-project。可在项目目录运行 pwd 查看路径。
  3. 先试只读审查：点击“新建任务”，选择项目与“代码审查”模板，填写“检查项目结构和启动方式，用中文给我一份报告”，再点击“开始审查”。
  4. 查看进度和结果：打开“查看详情”，在“事件”中看实时进度，在“输出”中看报告；只读审查结束后任务直接完成。
  5. 需要修改代码时：选择“先分析，审批后实施”。阅读方案后点击“批准并执行”；实施完成后检查“代码变更”，再选择“应用到原仓库”或“丢弃变更”。

新建任务前，请先提交或妥善保存仓库中已有的修改。“应用到原仓库”会把变更写回本机并加入 Git 暂存区，之后仍需你自行提交和推送到 GitHub。
